# 竖屏推广文案

## 标题

让电脑里的音乐，走到家里的每个房间。

## 配文

做了一个 Windows 上的小工具，叫「小米全屋播放」。

电脑正常播放，局域网里的音箱一起响。每台音箱可以单独调，按电脑音量键时，又能按调好的比例一起变大、变小。

窗口关到托盘，播放继续；真正点「退出」，声音回到电脑原来的播放设备。

0.6 源码预览版，已实测两台小米 Sound 加一台 Sound Pro。需要 Python、VB-CABLE 和 FFmpeg，配置方法见使用说明。
