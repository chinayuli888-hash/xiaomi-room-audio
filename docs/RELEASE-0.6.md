# 小米全屋播放 0.6 · Windows 源码预览版

让 Windows 默认媒体声音通过局域网在多台音箱播放。每台音箱独立调节，Windows 总音量按原比例联动；隐藏到托盘可继续播放，点击「退出」恢复原播放输出。

## 下载和开始使用

1. 下载 `xiaomi-room-audio-0.6-windows-source.zip`，解压到一个固定目录。
2. 按压缩包内的 `USAGE.md` 安装 Python 3.12、VB-CABLE 和支持 DirectShow 的 FFmpeg。
3. 安装 Python 依赖，复制示例配置并填写音箱地址。
4. 双击 `小米全屋播放.vbs`，点击绿色播放按钮。

也提供单独的 `USAGE-0.6.md` 和 `SHA256SUMS.txt`。下载包是可运行的源码预览，不含独立 EXE、Python、驱动或 FFmpeg。首次使用从低音量试听。

## 这一版

- 逐台拖动滑杆调整音量，Windows 总音量控制整组比例。
- 支持按音箱配置接收端音量上限，黑白 Sound 实测可解除原固定衰减。
- 起播不超过 10%，继承系统静音；后台播放和正常退出恢复设备。
- 调整音量滑杆的视觉与操作反馈，补齐中文说明、来源记录和第三方许可。
- 配对时要求有效的服务器证明；已用三台音箱完成无声握手验证。

## 验证与限制

- Windows 下已实测小米 Sound 黑、白及 Sound Pro 三台联播。
- 黑白两台同样 20% 滑杆设置，接收端从 −12 dB 改到 0 dB 后，内麦匹配扫频分别提高约 13.1 / 12.6 dB；Pro 设置未改。
- Windows 5% → 10% → 5% 的实测，三路发送幅度按各自原比例翻倍后恢复。
- 先前版本从虚拟声卡到内麦拾音约 0.69 秒；不同网络和设备可能不同。本版未完成逐台声学同步差或全天运行验收。
- 需要手动配置同一局域网的音箱地址。独立项目，与小米、Apple 官方无关。
