# 0.6.1 预览版验收摘要

日期：2026-11-18。范围：Windows 本机、当前局域网中的两台小米 Sound 和一台 Sound Pro。这里记录本轮验收结果，早期声学测量与本轮检查分别说明。

| 检查 | 结果与范围 |
| --- | --- |
| 自动化测试 | 50 项通过，覆盖发现去重、移除与取消、网络身份变化拒绝旧结果、设备列表状态、音量比例和恢复等行为。测试中的网络变化由模拟输入触发。 |
| 当前网络连接 | 三台音箱建立三路会话，连接连续保持 60 秒。该结果不等于已经对每台音箱分别录音确认连续出声。 |
| Windows 总音量 | 本轮复核三路按已有比例一起升降；未用混合麦克风录音推断各台的实际声压。 |
| 正常退出 | 按应用退出流程结束连接，并确认默认媒体输出回到电脑原来的播放设备。 |
| 采集队列 | 运行中仍有丢弃记录；不宣称零丢帧或已通过长期稳定性验收。 |

## 本轮尚未验证

- 没有真的切换到另一个 Wi-Fi 做现场验收。自动化测试覆盖网络身份改变后的旧结果失效、停止与恢复逻辑，不能替代真实换网测试。
- 没有重新录音测量 0.6.1 的端到端延迟。README 中约 0.69 秒来自早期 Windows 预览版的虚拟声卡到电脑内麦测量，不是本轮新结果。
- 没有逐台测量音箱到达时间差，也没有扩大到其他型号、跨子网或更长时间的连续播放。

## 使用上的边界

发现只限当前活动 IPv4 接口的同子网，设备还需广播 AirPlay 2 能力并通过 TCP 连通性检查；发现成功不等于配对或播放一定成功。一次最多 8 台，超过上限时需要减少参与设备数量。

启动时自动搜索但不自动播放。每次点击「AP2 直推」会重新扫描，再连接本轮结果。网络身份改变后的目标行为是按正常流程停止旧会话、恢复电脑输出、清空旧列表并搜索；不会自动在新网络开始播放。

上述限制应与预览版一同保留，不能把连接计数、模拟测试或旧版录音数据改写成已完成的现场声学验证。
